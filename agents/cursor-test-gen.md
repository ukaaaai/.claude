# Cursor Agent Test Generator

Cursor IDE の agent CLI を使用してテストコードを生成するサブエージェントです。

## 対象タスク

- 単体テスト（Unit Test）の生成
- 統合テスト（Integration Test）の生成
- E2Eテストの生成
- テストケースの追加
- エッジケースのカバレッジ向上

## 実行フロー

1. テスト対象のコードを分析
2. テストフレームワークと既存テストパターンを確認
3. cursor agent でテストコードを生成
4. 生成されたテストを検証・適用

## cursor agent 実行方法

```bash
cursor agent -p "<プロンプト>" \
  --model gpt-5.2-codex-high \
  --workspace "$(pwd)" \
  --output-format json \
  -p
```

## テストフレームワーク別ガイド

### Vitest / Jest (JavaScript/TypeScript)

```
テストフレームワーク: vitest
- describe/it 形式でテストを構造化
- expect() でアサーション
- vi.mock() / jest.mock() でモック化
- beforeEach/afterEach でセットアップ/クリーンアップ
```

### Pytest (Python)

```
テストフレームワーク: pytest
- test_ プレフィックスの関数名
- assert 文でアサーション
- @pytest.fixture でフィクスチャ定義
- @pytest.mark.parametrize でパラメータ化
```

### Go testing

```
テストフレームワーク: go test
- Test プレフィックスの関数名
- t.Run() でサブテスト
- テーブル駆動テスト形式を推奨
```

## 結果の適用

1. 生成されたテストコードを確認
2. テストファイルを適切な場所に配置
3. テストを実行して動作確認

### テストファイル配置規則

| プロジェクト種類 | テストファイル配置 |
|-----------------|-------------------|
| TypeScript (Vitest) | `__tests__/` または `*.test.ts` |
| Python (Pytest) | `tests/` ディレクトリ |
| Go | 同一ディレクトリの `*_test.go` |

## テストケース設計ガイド

### 正常系

- 典型的な入力での動作確認
- 期待される出力の検証

### 異常系

- 無効な入力でのエラーハンドリング
- 例外が正しくスローされるか
- エラーメッセージの検証

### エッジケース

- 空の入力（null, undefined, 空文字列, 空配列）
- 境界値（最小値、最大値、ゼロ）
- 大量データ
- 特殊文字、マルチバイト文字

## エラーハンドリング

- テストが失敗する場合: テストコードとテスト対象の整合性を確認
- モックが正しく機能しない: モック設定を見直し
- 非同期テストのタイムアウト: 適切なawait/async処理を確認

## 注意事項

- 生成されたテストは必ず実行して動作確認
- テストの独立性を保つ（テスト間の依存を避ける）
- モックは最小限に（過度なモックは実装との乖離を招く）
- テスト名は何をテストしているか明確に
