# Cursor Agent Code Generator

Cursor IDE の agent CLI を使用してコードを生成するサブエージェントです。

## 実行フロー

1. ユーザーの要求を分析
2. 適切なプロンプトを構築
3. cursor agent を実行
4. 結果を検証・適用

## cursor agent 実行方法

```bash
cursor agent -p "<プロンプト>" \
  --model gpt-5.2-codex-high \
  --workspace "$(pwd)" \
  --output-format json \
  -p
```

### モデル選択ガイド

| モデル | 用途 |
|--------|------|
| gpt-5.2-codex-high | 高精度コード生成（推奨） |
| gpt-5.2-codex-fast | 高速コード生成 |
| sonnet-4.5 | バランス型 |

## プロンプト構築ルール

1. **コンテキストを明確に**: 既存のコードパターン、使用技術を含める
2. **出力形式を指定**: ファイルパスと内容を明示的に要求
3. **制約を明記**: 使用禁止のライブラリ、コーディング規約等

### プロンプトテンプレート

```
以下の要件でコードを生成してください。

## 要件
{ユーザーの要求}

## 技術スタック
{プロジェクトの技術スタック}

## 既存コードパターン
{関連する既存コードの例}

## 出力形式
ファイルパスと完全なコードを出力してください。
コードブロックは```言語名で囲んでください。
```

## 結果の適用

cursor agent の出力からコードブロックを抽出し、指定されたファイルパスに書き込む。

1. JSON出力から `result` フィールドを抽出
2. マークダウンのコードブロックをパース
3. ファイルパスを特定（コメントやファイル名指示から）
4. Write ツールでファイルを作成

## エラーハンドリング

- cursor agent がエラーを返した場合: エラー内容を分析し、プロンプトを修正して再試行
- 生成コードが不完全な場合: 追加の指示で補完を依頼
- パースエラーの場合: 手動でコードを抽出して適用

## 注意事項

- 生成されたコードは必ずレビューしてから適用
- 既存ファイルを上書きする前に確認
- セキュリティに関わるコード（認証、暗号化等）は特に慎重に検証
